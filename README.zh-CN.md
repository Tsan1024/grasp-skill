# Grasp · 抓住主脉

[English](README.md) | 简体中文

快速理解陌生领域：先看清全貌与关键关系，再通过少量追问检验理解。

## 从这里开始

安装后，说出主题并告诉 Agent 你是初学者即可：

```text
$grasp 帮我理解 Agent Memory。我是小白，先抓主脉。
```

不需要额外配置。未指定深度时，Grasp 先给一份简短导览，再提出一个核心问题检验理解。以下示例使用 Codex 的 `$grasp`；Claude Code 请改用 `/grasp`。尚未安装时，先看[安装说明](#安装)。

## 选择理解深度

这些是自然语言需求，不是必须记住的固定命令模式。时间指大致阅读或学习量，不代表生成耗时或保证达到精通。如果需要在某个截止时间前拿到答案，请另行说明。

| 你的需求 | 可以怎么说 | 内容如何变化 |
|---|---|---|
| 先看一眼全貌 | 5 分钟版本 | 核心问题、小地图、一个例子和少数关键概念 |
| 快速理解（默认） | 5—15 分钟版本 | 主要关系、必要机制和适用边界 |
| 多一些解释 | 30 分钟版本 | 增加案例，比较不同路线为什么出现 |
| 系统建立框架 | 约 1—3 小时学习材料 | 发展脉络、代表来源、成立条件、争议与选择性深入材料 |

直接复制并替换主题：

```text
$grasp 给我 Agent Memory 的5分钟版本，只保留主脉，先不检验。
```

```text
$grasp 给我 Agent Memory 的30分钟导览，重点讲主要路线为什么出现，用例子解释差异。
```

```text
$grasp 系统梳理 Agent Memory，提供约2小时的学习材料，包含代表来源，并区分必读与可暂缓内容。
```

## 检验自己是否理解

检验与导览长短相互独立。Grasp 通常先问一题，你用自己的话回答后，它根据回答决定下一问。一般约 3—5 轮，检查目的、关系和简单新场景中的判断，随时可以停止或跳过。

```text
我读完了，逐个问我几个核心问题，检查是否抓住主脉。等我回答后再反馈。
```

如果你已经在别处学过：

```text
$grasp 检验我对数据库的理解。这是我已经学习的内容：[粘贴笔记或自己的解释]。
```

最后的反馈会说明你的回答展示了哪些理解、哪里仍不稳，不会据此宣称你已经精通。

## 沿着已有地图继续

留在同一对话里，直接说出需要：

| 遇到的情况 | 可以继续这样问 |
|---|---|
| 太抽象 | “用一个生活中的例子解释，少用术语。” |
| 某个关系不清楚 | “检索在整个记忆生命周期中处于什么位置？” |
| 想深入一处 | “展开讲更新机制，其他部分保持简短。” |
| 想了解最新变化 | “查阅近期来源，说明哪些进展改变了这张地图。” |
| 想保存笔记 | “把地图和我答题时混淆的点保存为 Markdown。” |
| 图解更容易看懂 | “做一个 HTML 导览页，包含关系图和可展开的细节。” |

第一次使用，建议先读短版，再回答几个核心问题，最后只深入仍不清楚的部分。不必在第一条消息里填写所有偏好。

## 你会得到什么

- 一句话定位：这个领域是什么，为什么存在。
- 一个具体案例：用熟悉的场景串联概念。
- 整体地图：主要部分以及它们如何关联。
- 理解主线：主要路线为什么出现，各有什么边界。
- 少数核心概念或矛盾，以及可以暂缓的细节。
- 通常 3–5 轮、每次一题的理解检验：定位、因果关系、简单场景迁移。

默认在对话里交付；需要保存时生成 Markdown，图解或交互确有帮助时按需生成 HTML。检验可以跳过，参考解释在回答后给出。

Grasp 帮助建立初步整体理解，不承诺通过一篇导览或几道题达到精通。

## 适用范围

适合初次接触研究领域、技术系统、复杂产品、人文思想或行业。对实践技能，它适合先了解子技能和反馈结构；具体操作、专业判断和熟练程度仍需要专项学习与实践。

## 联网策略

稳定基础知识可以直接解释。用户要求调研、最新信息、查阅具体来源，或关键事实不确定时，使用环境提供的检索能力查证。没有联网能力时，明确未核实的信息。模型更新频率不能保证具体事实的新鲜度。

## 安装

把下面这段话发给你的 Agent：

```text
请从 https://github.com/Tsan1024/grasp-skill 安装 grasp，
安装到当前 Agent 的个人范围，并确认安装后可以发现它。
```

你的 Agent 需要能够访问 GitHub，并具备安装本地 Skill 的能力。

## 调用 Grasp

Codex 使用 `$grasp`，[Claude Code](https://code.claude.com/docs/en/skills) 使用 `/grasp`。其他客户端可通过 Skill 选择器，或直接说“用 grasp 帮我理解数据库”。显式调用语法由客户端决定。

若未发现已安装的 Skill，重新加载 Skills 或新开会话。回答语言跟随用户。

## 文件结构

```text
grasp/
├── SKILL.md
└── agents/openai.yaml
```

逐题追问的交互方式受到 `grill-me` 启发；这里聚焦宏观理解检验，控制轮数，并在作答后提供反馈。
